# SURVIVAL X

A top-down survival shooter. Fight through enemy waves, collect drops, and beat your high score.

## Source code

The [SurvivalX GitHub repository](https://github.com/sibhakhalid/SurvivalX) contains the game source. Run it locally using the steps below.

## Controls

| Action | Controls |
| --- | --- |
| Move | `W`, `A`, `S`, `D` or arrow keys |
| Aim | Mouse |
| Fire | Left mouse button |
| Reload | `R` |
| Switch weapon | `1`, `2`, `3` |
| Pause or resume | `Esc` or `P` |
| Toggle sound | `M` |
| Deploy or restart | `Enter` |

Your best score is saved in your browser.

## Run locally

**Requirements:** Node.js 20.19+ or 22.12+, and npm.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite in your browser.

## Build

```sh
npm run build
npm run preview
```

The production-ready, single-file site is generated in `dist/`.
